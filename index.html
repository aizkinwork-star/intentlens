Privacy & Data ▼
IntentLens is local-first, not fully offline. Camera preview, grid, tap-to-track and the k-NN reference index run on this device. Analyze sends only the captured frame, your command and relevant task/object context to the Meta model host you selected.
Requests use your own provider credential and are subject to that provider's policies, quotas and billing. No continuous live video is streamed. There is no local LLM; speech recognition and TTS may use device/platform services.
You can remove credentials, clear logs and delete local project data here. Cloudflare states stateless Workers AI requests have zero data retention after processing (subject to exceptions); other providers have their own terms.

Connect Vision AI Provider

Meta models only · your key stays on this PC

Camera preview, grid, tap-to-track and the k-NN reference index run locally. Cloud AI is optional and sends a captured frame only when you press Find it. There is no local Llama model on this machine.

Pre-filled with NVIDIA's inference host. build.nvidia.com is a dashboard page, not an endpoint.
Stored encrypted with Electron safeStorage or Windows DPAPI. Never returned to this page or written to logs.
Cloud requests are disabled for this install (ALLOW_OUTBOUND_NETWORK=false). Camera, grid and local k-NN still work. You can allow cloud requests for this session only, or set ALLOW_OUTBOUND_NETWORK=true and restart.
📖 Where to get a key ▼
All three providers use one account-wide key. You do not need a separate key per model. Only Meta vision models are allowed for images; text-only Meta models are never sent an image. Model entries marked verified have answered a real image request on this account; others still need a test.
NVIDIA NIM (first in failover order): sign in at build.nvidia.com, click Get API Key, and paste the nvapi-... value. The inference base URL is pre-filled (https://integrate.api.nvidia.com) - leave it as-is. Muse Glimmer 30B is the verified model here; on the account we tested, Llama 3.2 11B returned 404, Llama 3.2 90B timed out, and Llama 4 Maverick is end-of-life. Muse Glimmer is a reasoning model: a full analysis can take 80-120 seconds.
Cloudflare Workers AI: in dash.cloudflare.com copy the 32-character Account ID, then create an API token at My Profile → API Tokens → Create Token. Use Custom token, add the permission Account → Workers AI → Read (or Read all resources), scope it to your account, and paste the token and Account ID above. A token that only has R2/Workers permissions will fail with 401.
Groq: at console.groq.com/keys, create an account-wide key (gsk_...) and paste it above. On the account we checked, the playground exposed only Meta Prompt Guard models, so Groq vision is not verified. Test before relying on it.
Links open in your default browser (Chrome, Edge, ...). If nothing opens, copy the address manually.
Failover: NVIDIA is tried first, then Cloudflare, then Groq. Auth, quota, rate-limit and outage errors move to the next configured provider. Existing track IDs, corrections, instructions and TTS are preserved across failover.
